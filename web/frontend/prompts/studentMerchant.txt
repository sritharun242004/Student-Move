### 6.1 Create Voucher
### POST `/vouchers`
- **URL:** `{{baseUrl}}/vouchers`
- **Headers:** BAREAR TOKEN, `Content-Type: application/json`
- **Body:**
```json
{
  "offerId": "{{offerId}}"
}
```

Response includes `uniqueCode`
